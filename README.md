# Artikelregistreringsunderlag

Detta verktyp används för att generera ett underlag med nödvändiga uppgifter för upplägg av nya artiklar i Sesam.

Verktyget är skapat med hjälp av följande fria programvaror och bilder:

* [MDUI](https://www.mdui.org/) av [zdhxiong](https://github.com/zdhxiong/mdui)
* [jQuery JavaScript library](https://jquery.com/)
* [Typsnitt från Google](https://developers.google.com/fonts)
* [Bilder från Unsplash](https://unsplash.com/)
